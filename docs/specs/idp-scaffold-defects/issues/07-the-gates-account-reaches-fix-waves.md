# 07 — The gates account carries the toolchain and reaches fix waves

**What to build:** a **fix wave** starts warm on the **gates** a delivery's implementers already met, including where
the toolchain they needed lives and how it was got, instead of installing or searching for one already on disk. The
build skill's first carry-forward exception widens to say so and to reach each `comments-addresser`; the rule that
every other fact is met first-hand stays as written. Settled under **The gates account** in `../spec.md`.
